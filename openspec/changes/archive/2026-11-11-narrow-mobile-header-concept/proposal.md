# Narrow the mobile header concept

## Why

The owner withdrew removing the black announcement strip and exposing a second mobile navigation row, while retaining the compact first-row tools, especially the smaller bag control. A follow-up explicitly retains the bottom Help & Support drawer entries.

## What Changes

Revise the local concept and review board to restore the original rotating strip and drawer-based mobile navigation. Retain the compact mobile tools row and Help & Support entries, restore desktop bag-label presentation, update current documentation and replace superseded screenshots.

## Capabilities

Documentation/prototype correction only; skip_specs. No runtime requirements or production code are changed. The prior design was never implemented or deployed.

## Impact

Only docs/design/mobile-header and this record. Future runtime work is limited to the compact mobile toolbar and drawer help entries; strip removal and two-row navigation are cancelled.
