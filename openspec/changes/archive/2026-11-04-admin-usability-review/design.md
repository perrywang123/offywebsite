# Offy 合作账簿：统一、可核对的工作区

用户为品牌唯一管理员，核心任务是新增合作、分发合作包、核对订单/诊断与登记结算。保持暖灰画布、白色工作表面、墨色主操作、灰色说明；绿色表示已核验，橙褐表示待处理，红色仅表示错误与危险。系统 sans，金额 tabular-nums。拒绝装饰统计卡、渐变、新图表和外部字体。

## 实施契约

- 搜索、下拉、日期均有可见关联标签；控件白底、44px高、统一边框和8px圆角。标签12–13px，正文14px，字段间12px、区块间24px。刷新文案变化不能推动相邻主操作。
- 筛选根据实际内容宽度换行，不压缩日期；手机搜索独行，其余最多两列，空间不足时单列。日期错误明确说明，提供当前栏目清空恢复。所有空态区分全空与筛选无匹配。
- 手机订单/诊断默认收起高级筛选，展开按钮提供条件数量与 `aria-expanded/controls`；已选摘要、清空与错误留在折叠层外。日期起止始终为同一组，订单搜索和刷新同排以让首条结果进入首屏。桌面高级字段保持展开。
- 手机页头占满一行，连接/账户等次要动作单独一行。五栏目始终可发现；保留站内导航和各账簿栏目筛选。
- native dialog 头、正文、页脚分离；正文为唯一滚动区，页脚正常流不叠在字段上，无负 bottom。所有表单保留 native validation、Esc、返回焦点和错误定位。诊断只读详情使用同一滚动规则。
- 确认弹窗展示已有数据可得的目标名称、编号/月度、金额和币种；不新增远端写入或财务动作。结束绑定、取消、人工冻结等危险/后果动作有明确文案和次级层级。
- 常规表格窄屏使用 data-label 等方式形成带名称的记录摘要，金额和动作完整保留；保留表格语义。复杂比较仅在有名称、可键盘到达的局部区域横滚；页面本身不横滚。姓名、码、ID、URL、原因可换行。
- 主空态紧凑且说明下一步；子区空态避免再次占250px。没有记录时不输出演示金额，负金额不隐藏，币种不合并。

## 验收

360、375、768、900、901、1024、1280、1440、1920px核对无整页横向溢出。1440px订单同排筛选控件顶底误差≤1px、44px高；375px弹窗首/中/末所有字段与底部操作可完整看到且无交叠。以隔离实数验证五栏目，包含长名称/码/URL、真实模拟核验/退款后的负调整与诊断多商品。检查无匹配清空、倒置日期、确认目标、键盘和减少动效；先行为失败测试，后实施，最终全量测试/类型/lint/构建和专家复评。
