# Why

用户反馈后台多处布局不完整，要求交互专家、美术专家独立评测打分，再交研发实施与测试。当前订单筛选缺少统一可见标签、日期与下拉背景/尺寸不一致；手机表单页脚覆盖字段；空态、长内容、窄屏表格和确认上下文有可用性缺口。

# What Changes

- 合并两位专家的问题，建立五栏目共用字段、筛选、页头、列表、空态与 native dialog 设计契约。
- 提供当前栏目清空筛选；订单/诊断日期倒置显示明确原因，不伪报无结果；优惠码/月结筛选零匹配给恢复入口。
- 弹窗使用固定头部、唯一滚动正文、正常流独立操作页脚，保证手机字段和保存操作不重叠。
- 高影响动作确认显示只读目标摘要，沿用现有服务端核验；统一危险/普通操作层级。
- 修复宽度断点和长内容；手机表格优先转换成带字段标签的记录，确需列比较的局部滚动明确可键盘操作。
- 使用临时数据库和本地 Shopify 模拟器检查有数据、无匹配、长文本、负调整、多商品与完整动作；改后按同一量表复评。

# Capabilities

ADDED: `kol-platform` 的 Consistent administrator workspace usability。

# Impact

`src/components/kol/`、管理 CSS、相邻测试、设计/验收文档。保留之前的单名称表单与持久导航；不改财务计算、认证、Shopify 权益、归因规则、数据库与部署配置。评测为专家启发式判断，不代表真实用户实验或生产支付验收。用户已授权评估后直接实施；无需再次请求方案批准。
