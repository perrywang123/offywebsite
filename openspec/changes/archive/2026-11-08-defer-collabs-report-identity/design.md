# Scope

按用户确认范围，仅解除短链创建对报告身份的依赖。未取得真实报告时不猜测姓名、邮箱、Collabs creator ID 与报告标识的对应关系。官方真实落地地址可直接作为既有链接输入，不修订跳转、结账或 Shopify Analytics 逻辑。

# Data and lifecycle

`collabs_creators.creator_key` 改为可空且保留唯一索引。省略、NULL、空白输入统一为 NULL；多个未绑定合作可共存。NULL 可后补为真实报告标识一次，非空标识不可改写或清空。别名永久保留。绑定操作及普通编辑沿用管理员鉴权和审计。

迁移仅重建链接索引表，不变更财务报告、诊断或旧 KOL 数据；在既有 Drizzle 迁移事务内完成。测试保留历史链接、已绑定身份和唯一索引，并使用旧表结构定义读取新库，验证运行中独立站只读链接逻辑兼容。

# Reconciliation

未绑定记录不参与来源创作者匹配，也不按展示名或别名匹配。工作台及核对结果提示待绑定；仍可独立核对有真实订单标识的 Shopify 订单，不能把这解释成创作者归因已验证。Collabs 原始金额、付款证据与原生计佣规则不变。

# Release

质量检查与预构建在本地/CI 完成。服务器使用 revision 校验及既有在线备份后执行后台 `--prebuilt` 发布，记录 app 的容器 ID、镜像、启动时间和 Nginx 配置校验值，禁止服务器编译及 storefront 发布。真实测试只保存内部推广链接，不导入模拟财务报表。
