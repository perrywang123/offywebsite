# Why

首位 Collabs 合作在取得官方销售报告前，需要先启用 Offy 推广短链。当前必填且不可修改的报告创作者标识把这两个独立步骤绑在一起，迫使管理员猜填来源身份。

# What Changes

- 允许报告创作者标识留空，以数据库 NULL 表示尚未绑定，不生成虚构来源标识。
- 空标识可在取得真实报告后绑定一次；已绑定标识和推广别名继续保留唯一性与不可转让约束。
- 表单、合作卡片及报告核对明确提示待绑定状态；不按姓名或别名猜测报告归属。
- 追加迁移，保留既有记录、官方报告和审计；单独发布管理后台与 worker，独立站容器不替换。

# Capabilities

## New Capabilities

- `collabs-link-index`: 短链建档与报告身份后补的生命周期、核对边界及迁移兼容性。

# Impact

仅涉及 Collabs 管理端、数据约束、核对提示和相关文档。购物车、结账、商品价格、Shopify 域名及 Collabs 原生计佣规则不变。本次使用已获授权的内部合作与真实落地地址建立 `/r/perry-test`；不创建订单或执行付款。
