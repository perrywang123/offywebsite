# Why

后台侧栏使用普通 `<a>`，每次切换触发整页导航；管理控制台在叶页面内重复挂载，初始数据未到时替换整个后台为“正在连接合作账簿”。即使只有本地数据，也会反复闪屏。

# What Changes

- 使用 Next.js 站内链接，控制台上移到共享管理 layout 中，五个合法 URL 继续支持直接打开、前进和后退，非法地址仍 404。
- 保留框架和最近数据，切页执行后台刷新，首次进入才显示连接态；请求取消及身份失效不允许旧响应覆盖新状态。
- 合作、码、订单、月结的筛选独立保存；诊断沿用 URL 筛选，切换关闭临时对话框；刷新失败保留数据并明确提示，401 清除数据并显示登录。
- 结账诊断保留局部读取，不用整个后台的连接态遮盖导航。

# Capabilities

ADDED: `kol-platform` 的 Persistent management navigation。

# Impact

管理 layout/page、客户端控制台/工作区、相邻测试和当前操作文档。无数据库迁移、无配置改动、无公开主站链路变动。认证、可信入口和 mutation 检查保留。验证使用隔离临时数据库。
