## Why

The owner found the new About pages' phone typography disorderly. Centered long prose shares the same scale as short manifesto lines, producing uneven wraps and a weak reading hierarchy.

## What Changes

- On phones, left-align the About title and manifesto, distinguish three opening statements from the quieter closing paragraph, and use consistent reading gutters.
- Give the story a mobile reading scale: clear numbered headings, smaller supporting labels, comfortable body text and deliberate paragraph/quote spacing.
- Preserve all PSD copy, artwork, order, desktop composition, routes and storefront interactions. Local preview only.

## Capabilities

### Modified

- `brand-site`: responsive About/story editorial typography.

## Impact

Only `AboutStory.module.css`, design/spec records and local visual evidence. No commerce, Shopify, tracking, server or production changes. This is a presentation-only refinement: use existing source-content tests and real browser geometry/visual checks rather than implementation-mirroring CSS tests.
