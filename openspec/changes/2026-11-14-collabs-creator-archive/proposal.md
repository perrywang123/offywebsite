# Why

Offy 的 Collabs 工作台仍显示三条已明确为测试用途的合作记录，历史重复 dt_id 干扰真实合作和统计。管理员缺少安全清理已结束合作的入口。

# What Changes

- 增加管理员手动归档及恢复：明确选择原因并确认，归档关闭 Offy 短链，默认列表和访问统计排除该记录；恢复后短链仍停用。
- 保留合作身份、推广标识、浏览历史、官方归属、报告和审计；归档后不能通过编辑重新启用，别名和标识不能转给其他人。
- 提供折叠的已归档记录和显式包含归档数据的统计开关，历史报告仍能核对原创作者。
- 用追加式表保存归档状态，兼容现有独立站镜像；仅发布后台和后台 worker，主站及支付配置保持。
- 核对 Shopify Collabs、Flow、Offy 短链和访问/订单证据的实际状态，记录问题与数据边界，不擅自调整官方合作或财务状态。

# Capabilities

## Modified

- collabs-link-index: 手动、可恢复的合作记录归档。
- collabs-observation: 归档记录在观察统计中默认排除，显式可查看历史。

# Impact

增加 SQLite 归档表、管理员 API 和现有工作台交互；不删除历史数据、不改变 Collabs 计佣/付款、不发送邀请、不修改 Shopify 商品、订单或结账。清理对象为用户指定的 perry6、peiyu、perry wang（内部验证）。
