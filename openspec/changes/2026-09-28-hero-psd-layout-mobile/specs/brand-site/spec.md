## MODIFIED Requirements

### Requirement: 首页头图轮播

首页头图轮播 MUST 按主 PSD(`is.offy 网站.psd`)UI 树呈现 5 屏,系列屏 MUST 采用
「玩偶上半 + 左下标题组」布局,并 MUST 在移动端等比缩放且文字不溢出。

#### Scenario: 系列屏左下标题组

- **WHEN** 用户浏览到轮播第 3/4/5 屏(公主lady/时尚潮流生活/趣味生活)
- **THEN** 左下展示「OFFY+系列名」标题图(约 x11.5%、y62% 头图区)、副标题
  (生活需要仪式感/周末出门玩/日常犯可爱,与 OFFY 行右对齐)、
  「查看详情」按钮(系列名行右侧,点击跳对应系列页)
- **AND** 时尚屏标题/副标题为白色(深色背景),其余屏为深色字

#### Scenario: 移动端等比适配

- **WHEN** 视口宽度 ≤768px
- **THEN** 头图所有文字/标题图按视口等比缩小(clamp 约束下限),
  过长标题允许换行且不被截断

#### Scenario: 高清资源

- **WHEN** 渲染轮播
- **THEN** 字标/玩偶/箭头使用 PSD 原版导出资源(字标 596×224、
  促销玩偶 2882×1905、箭头 50×23 PNG)
