# Database Specification

## Purpose
Define the persistence layer and its operational contract.

## Requirements

### Requirement: Local development database
The system SHALL use SQLite with zero external dependencies for local development.

### Requirement: Production database (reserved)
The system SHALL support PostgreSQL in production by switching `DATABASE_PROVIDER` while keeping the same Drizzle schema. (Reserved — not yet implemented.)

### Requirement: Schema migrations
The system SHALL manage schema changes through versioned migrations generated by drizzle-kit and applied with the migration runner.
