- Spec-first 变更 `add-collabs-observation` 校验通过；先运行失败测试，再实现接收、计数及界面。
- 全量 Vitest：115 个文件、794 项通过。首次并行执行生产构建时，两项部署脚本夹具超过15秒；停止资源竞争后，部署夹具38项和完整套件均通过，没有修改生产部署逻辑或放宽测试超时。
- TypeScript、ESLint、Prettier（本次文件）、`git diff --check`、生产 standalone 构建通过。
- 隔离 HTTP 流程32项通过：短链303及原生参数保留、计数、报告身份可后补、Flow 入站鉴权与重复事件、官方身份显式绑定、自动读取模拟订单、导入报告及退款提示。模拟支付仅存在于本机 Shopify 模拟器，不连接真实店铺或网关。
- 单元覆盖：未采集历史、期间与累计分离、HEAD/预取/预览排除、统计故障不阻断跳转、无访客cookie；错店铺/无效身份/非预期个人字段/过大输入拒绝、乱序快照、未知创作者、订单查询失败保留并退避重试、不猜佣金币种。
- 只校验入口验证有效负载不打开数据库，不持久化模拟事件。
- 凭据准备脚本验证了用途派生一致、0600文件权限和标准输出不含凭据；不改变现有内部认证。
- 浏览器检查360×800、768×1024、1440×900、1920×1080；发现新订单表格导致窄屏整页溢出后，修复为表格内滚动。复验各尺寸文档宽度等于视口宽度。验证了周期、短链选择及每日明细；保留手机端未采集图例。

官方 Flow 已在店内存在，并有活跃的既有弃单恢复流程。本次新建独立草稿 `OFFY · Collabs attribution observation`，仅有 `Order Attributed → Send HTTP request`。实际变量契约已从官方编辑器核实，模板与配置保存在仓库；原有流程未修改。

## 生产验证

发布前主站和后台健康，Nginx与数据基线已捕获。服务器不执行编译，计划使用相同Git提交的CI Linux镜像，先后台迁移与worker，再单独更新主站。正式部署、Flow凭据授权和只校验请求的实际结果将在完成后补充，不能仅凭本地验证认定已启用。

## 证据边界

真实 #1134 已在 Collabs 原生门户产生 USD 4.71 冻结佣金，该事实在本次功能前已核实。本次不生成或重放一条假的 #1134 官方事件，也没有执行真实付款、退款或佣金调整。新增流程的未来真实事件需要在实际到达后核对；模拟校验成功不能代替真实转化或 KOL 到账证据。

自动来源提供的是事件时累计快照，没有明确的金额币种或逐笔佣金/出款，财务报告继续人工导入；没有新归属事件时，官方访问快照不会单独更新。Offy打开请求可能包含未识别机器人，采集失败可能少计，不作为应付佣金依据。此前已发现的点路径校验问题仍未改动，等待原范围单独确认。
