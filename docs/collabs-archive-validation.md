# Collabs 合作归档与链路核验

2026-11-14。本轮增加可恢复的 Offy 合作记录清理，并只读核对 Shopify Collabs、Flow 与 Offy 的实际数据。功能代码和发布状态分别记录；未经发布验证的事项不写成已上线。

## 功能与边界

管理员在合作卡片选择“归档合作”，核对对象、选择原因并显式确认。归档原子地停用 Offy 短链并保存原因、操作者、时间和审计，重复提交不重复产生审计。默认列表及访问统计排除归档记录；已归档列表可恢复，但短链仍停用。普通编辑不能重新启用归档记录。

所有身份、历史打开、落地 PV/UV、报告和官方归属均保留；归档不释放别名或官方标识。报告匹配仍包含已绑定的归档身份，当前待绑定提示排除已清理的未绑定测试记录。官方归属显示已有归档关系，但不能给归档记录新绑定官方身份。

按 dt_id 汇总时，仅隐藏全部记录都归档的组；仍有未归档历史别名时保留完整原汇总，不重新分摊历史浏览。显式勾选“包含已归档的访问统计”可查看原统计。

新增 `0015_collabs_creator_archives` 表，不修改原合作表字段。归档时将原字段 `enabled` 设为 false，原生产主站镜像仍可关闭短链，无需替换主站。Collabs 合作终止、优惠码撤销、佣金和付款不在本地归档中执行。

## 测试与交互

先复现缺少服务与归档按钮、默认统计过滤及确认机制；再补充两个失败边界：旧周期请求迟到时重新显示归档统计，以及归档测试记录仍产生当前报告待绑定提示。实现后相关测试通过；最终全量 162 个文件、993 项测试通过，TypeScript、ESLint、格式和生产构建通过。

隔离 HTTP 工作流 53 项通过，覆盖归档确认拒绝、默认/历史统计、链接 410、恢复后仍停用、显式编辑启用、历史报告匹配、官方 Flow 身份保留；模拟订单和退款仅在独立 SQLite/loopback Shopify 模拟器中创建，没有向真实 Shopify 发送测试订单。

浏览器实际归档和恢复通过，已有官方订单归属在归档后仍显示。375px 与桌面检查没有整页横向溢出，恢复后短链保持停用；手机截图为[隔离归档页面](design/collabs-archive/local-archive-375.jpg)。源代码静态审查范围限定本轮变更，正则未发现凭据字面量；当前 SmartCR 环境没有 JS/TS grammar，不能声称提供该语言的 AST 覆盖，使用 TypeScript、ESLint 和测试补充核验。

## 真实链路只读核对

- Collabs 邀请制计划存在，页面显示 10% 佣金范围；付款冻结设置为 30 天。合作联系人页面显示 Verified。未修改任何官方配置、发送邀请或终止合作。
- 真实合作短链打开和按 dt_id 的落地 PV/浏览器 UV 已入库，不能把旧浏览器页或默认选中的未采集测试组当成全站未采集。短链请求与许可后的落地统计口径不同。
- 官方归属 Flow 处于活跃，已有真实事件入库，后台 worker 的对应订单查询成功且无错误。真实创作者编号尚未与 Offy 合作记录关联，需要核对身份后人工关联一次；不根据姓名或 dt_id 猜测并自动绑定。
- Collabs 官方已有历史成交，而接收器只含 Flow 启用后的归属事件；启用前订单不会自动回填。普通订单 API 不能伪造官方历史归属。
- 目前没有导入官方财务报表，故本地缺少完整佣金调整、账单、手续费和付款证据。官方归属累计金额字段没有币种，仍保留原始值，不能把订单实付金额当作 KOL 已到账。
- Collabs 官方 Sessions 仍显示 0，但 Offy 落地采集和官方订单归属有实际记录；不能断言官方浏览已经同步完整。官方浏览统计与 Offy 统计来源独立，需针对真实受许可访问核对官方 Analytics 接收与 Collabs 刷新；本轮未修改主站上报或为了测试增加真实 KOL 访问。
- Offy PV 只覆盖带 dt_id、允许分析的实际落地页，不是 KOL 整站访问→加购→结账→订单的同浏览器漏斗。站内导航去掉 dt_id、拒绝许可、跨设备、拦截和网络失败均可能形成观察缺口；当前落地采集首次网络失败没有有界重试。计佣继续以 Collabs 为准，扩大站内漏斗或调整主站上报需单独规划。
- 既有点路径推广目标校验边界仍在先前待确认事项中；本轮没有调整主站路由或支付。当前实际有效的合作目标为正常商品列表路径。

官方接入边界参考 [Collabs 自建独立站](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/custom-storefronts) 和 [Collabs 与 Flow](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/flow)。实际业务订单与金额核对详情保存在本机私密验收目录，不提交 Git。
