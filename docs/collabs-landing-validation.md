## 采集边界

PV 只计已允许分析并实际触发采集的 Offy 落地页；只访问 Shopify 域名不计入 Offy PV。UV 按匿名浏览器标识去重，不是准确人数。期间 UV 独立去重，不累加每日 UV。访客标识、成员及事件去重记录最多保留 90 天；匿名 PV 聚合保留。拒绝许可不新增标识，撤回会移除对应 UV 成员，浏览器限制、网络或脚本失败均可能少计。
