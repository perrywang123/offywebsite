# Offy 区域限定配置(实测拉取)

来源:Shopify Storefront API 逐国 `@inContext(country:)` 查询,共 30 个国家 / 37 个商品。

配置位置:**Shopify 后台 → 商品 → 发布(Publications/Markets)** —— 每个商品可选发布到哪些市场。不是 tag、不是 metafield。
