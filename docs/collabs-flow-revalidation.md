# Collabs 流程复验与 SOP 交付记录

2026-11-07。本轮复验以不影响真实订单、付款和独立站运行作为边界。

## 已发现并修复

1. **异步错误越过 API 错误边界。** 隔离 HTTP 实测未确认来源的导入返回空白500；原因是管理路由在try内直接返回异步操作，拒绝未被本层catch捕获。新增三项路由级失败测试后补上await，结构错误恢复400 JSON，已知业务错误返回安全409 JSON，内部细节不外泄。浏览器重复映射列现在显示“同一列不能重复映射”。
2. **连接弹窗仍描述旧财务同步。** Collabs模式原先保留旧扫描时间和“执行一轮同步”，容易被误认为可以自动同步Collabs报告。现改为“连接状态 / 重新检查连接”，说明人工导入并隐藏旧扫描、旧归因告警和旧同步操作。原Offy模式保留。新增交互测试验证不会调用sync写接口。

- 类型检查、ESLint与格式检查通过。OpenSpec先更新并验证；上述缺陷采用失败测试先行。
- 最终完整测试108个文件、764项通过。Node26本机存在实验性localStorage警告；不是业务失败，正式Docker/CI使用Node22。
- 隔离HTTP主链路19项通过：登录、短链、折扣传递、模拟结账与订单、报告预览/导入、幂等、只读订单核对、退款提示、追加复核及不新增本地应付。
- 补充HTTP边界20项通过：多币种分开、零与缺失分开、非法来源确认/日期/精度/订单标识、重叠报告、修订保留历史、汇总不冒称逐笔核实、恶意外链与管理目标拒绝、退出后访问拒绝。
- 浏览器在隔离环境实际上传TEST-ONLY CSV、选择字段、预览和导入；EUR1.25、USD0.00分开显示，销售额/付款缺失明确显示“未提供”。汇总核对显示已核实订单0及资料限制；既有模拟退款提示和复核说明可见。
- 线上只读核对：主站/后台healthy，端口保持127.0.0.1:3000/3001；CPU现场采样均接近空闲，没有生产构建。后台已连接Shopify，实际显示read_orders、read_discounts。Collabs工作台没有导入模拟报告，真实诊断记录仍可读。
