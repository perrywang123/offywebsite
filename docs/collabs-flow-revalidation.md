## 已发现并修复

1. **异步错误越过 API 错误边界。** 隔离 HTTP 实测未确认来源的导入返回空白500；原因是管理路由在try内直接返回异步操作，拒绝未被本层catch捕获。新增三项路由级失败测试后补上await，结构错误恢复400 JSON，已知业务错误返回安全409 JSON，内部细节不外泄。浏览器重复映射列现在显示“同一列不能重复映射”。
2. **连接弹窗仍描述旧财务同步。** Collabs模式原先保留旧扫描时间和“执行一轮同步”，容易被误认为可以自动同步Collabs报告。现改为“连接状态 / 重新检查连接”，说明人工导入并隐藏旧扫描、旧归因告警和旧同步操作。原Offy模式保留。新增交互测试验证不会调用sync写接口。
