## 实施原则

优先保持Shopify对商品/订单/支付的主责，运营后台补合作分佣台账，以及后续可能的站内编排和内容，不另造商品、库存或退款后台。收入来自可验签服务端事件；不把浏览器“成功”当成订单。文档估算不是排期承诺，工作量在spec与验收范围明确后评估。

恢复中文、替换CMS、PG迁移或新增支付方式均不是本次取消fallback的附带工作。未确认的方案不得合入主规范或标为完成。

一键部署工具已补齐，详见 [部署手册](deployment.md)：同Git仓库中主站/后台独立Docker容器和镜像、共用持久卷；主站与后台均有服务器Git独立更新脚本，首次启用可先主站后后台分次发布，保留备份和默认1 CPU / 1536 MiB构建预算。2026-11-07补充旧systemd服务拦截、512 MiB额外可用内存检查和镜像Git revision标签。后台更新包含worker与入口检查；主站更新不动后台/worker/Nginx。预构建镜像尚未实现；真实目标服务器Docker与证书/防火墙仍属于上线验收，不因本地测试通过而标记完成。
