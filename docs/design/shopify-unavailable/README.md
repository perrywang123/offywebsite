## 使用

HTML的图片引用项目现有`public/assets`，没有外部字体或商品API请求。应在仓库目录结构中打开；复制单个HTML到其他位置会失去相对素材。可用绑定本机的静态服务预览，然后打开`/docs/design/shopify-unavailable/index.html`。

中文工具栏是审阅界面，英文商店区域是顾客展示。模拟恢复只切换反馈，不生成或加载商品、价格、支付会话。故事/支持链接是现有公开站点链接。

## 验证记录（2026-10-31）

- HtmlDesign静态审计：通过、0警告。
- 浏览器检查五种场景 × 五种窗口宽度360/375/768/1440/1920，共25组；每组无文档横向溢出、唯一顾客区H1、已加载图片无损坏、可见顾客链接/按钮高度均≥44px。
- 审阅画布在桌面有左右24px空间并最大1440px；例如768窗口的画布720px、1440窗口画布1392px。375手机画布为375px。以上是原型尺寸验证，不冒充生产页面验收。
- 重试时disabled/aria-busy，失败后可再次操作并显示status；勾选模拟恢复后显示恢复反馈和继续购物入口。
- 抽屉支持关闭/遮罩/Escape和焦点圈闭；关闭后焦点落在Open bag。业务实现仍需对真实CartDialog重新测试。
- 所有外链带noopener noreferrer；审阅过程未点击结账或创建真实订单。

## 视觉复审

第一轮发现审阅栏挤压首屏、主行动偏下，已缩短桌面面板纵向节奏。第二轮统一近似灰阶，去掉不必要的颜色散点；将原型中外观像按钮的Bag改成可打开抽屉的真实控件。最终截图对应修订后的状态。

## 确认后的工作

用户确认展示后，按OpenSpec写失败测试，再改数据错误模型、缓存、页面、购物袋、三provider及SEO。当前HTML不能代替这些工程实现。
