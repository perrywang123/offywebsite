# Shopify 不可用展示 · 设计契约

状态：2026-10-31 用户已确认并授权实现。该目录保留原批准设计；运行时使用 CommerceUnavailable 及同一设计原则。

## 目标与方向

目标：顾客知道商店暂时取不到商品、已选商品没有丢，并能重试或继续了解品牌。视觉命题：让一次服务中断像 OFFY 世界里的短暂停顿，不像系统报错页面。

沿用主站白/灰底、墨色大标题、48px 胶囊主按钮和细分隔线。以现有 is.offy 手写字标作为唯一图形记忆点；商品故障页不借旧商品照片填空。首页品牌 Hero 可以保留，因为它不是故障商品列表的替代数据。

## 角色

- 墨色 #1d1915：标题/主操作；正文 #525252，辅助文字 #686868。
- 页面 #efefef，白色 #fff，边线 #e3e3e3，轻背景 #f7f7f9。
- 故障是可恢复状态，主画面不使用大红告警或技术图标。
- 展示字：现有系统 display 栈；正文/操作字：系统 sans；不加载外部字体。

## 排版和空间

桌面正文 16px，主标题 clamp(36px,5vw,68px)，手机标题 36px，辅助标签最低 11px。手机左右 16px；桌面 92% 版心；主行动 48px；文案宽度约 44ch。

列表和详情使用通用恢复面板，但标题随上下文变化。购物袋不显示商品占位行或 0 元小计；本地数量是可保留事实，商业字段验证前不展示。抽屉手机宽 88%、桌面 max448px；底部状态与关闭按钮始终可达。

## 交互与可访问性

主操作 Try again；次操作 Our story 或 All looks；Contact us 为明确链接。重试期间 disabled + aria-busy，结束后恢复可点，role=status 宣读结果。失败不转成永久 loading，无无限闪烁骨架；不承诺恢复时间。抽屉支持 Escape/遮罩/关闭按钮，焦点移入并在关闭时恢复。

确认稿中的场景、尺寸、模拟恢复开关是中文审阅工具，位于商店 UI 之外。模拟不调用 Shopify，不生成商品、价格、会话或订单；恢复成功只展示“可继续购物”的反馈。

## 验收

检查 360×800、375×812、768×1024、1440×900、1920×1080。所有场景无横向溢出，按钮≥44px；键盘焦点可见；reduced-motion 禁用装饰过渡；无商品、价格、技术错误码和假恢复倒计时。测试重试失败/恢复成功、场景切换、手机抽屉及关闭恢复。
