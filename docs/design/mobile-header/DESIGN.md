# OFFY 手机双行顶栏 · 待确认原型

状态：2026-11-11，仅设计与本地交互原型，尚未授权修改正式站点；根 DESIGN.md 仍描述现行实现。

## 目标与边界

从原来的「公告 + 单行工具栏 + 隐藏导航」收敛为「品牌工具栏 + 直接可见主导航」。用户已确认所有手机页面都常驻 NEW IN / SHOP / SERIES / ABOUT US，不随商品页切换成 Product / Review / Recommend。商品页没有新增 Review 功能。

黑色提示条整条移除，包括轮播中的运费和赠品文案；正文、FAQ、购物袋中的运费说明保留。桌面保持原单行主导航，仅移除黑条。此次不涉及商品数据、推荐算法、市场判定或结账。

## 设计方向

延续 OFFY 的黑白编辑式摄影界面，常用路径直接可见，工具缩为清晰图标。参考用户提供的 POP MART 双层结构与紧凑密度，使用 OFFY 原 Logo、颜色和信息架构，不复制其品牌和未具备的功能。

- 白色表面 #fff，页面 #efefef，商品图区 #f7f7f9。
- 主色 #1d1915，次文 #666，线 #e5e5e5，遮罩 rgba(29,25,21,.34)。
- 系统 sans；主导航 11.5px / 600 / 0.06em，一级标题延续现有商品字体。
- 8/12/16/24px 间距；沿用胶囊购买按钮，导航不新增胶囊、渐变或彩色标签。

## 顶栏

手机 <768px：第一行 56px（Logo、地球+国家码、购物袋图标/数量、菜单）；第二行 44px，四个主导航等宽。总高度 100px（另加必要安全区），全部按钮命中高度至少44px。移除 BAG 文字胶囊，释放顶部宽度；Logo保留左对齐。320px不折行。

两行整体 sticky top 0，向下浏览不消失或变高，不使用隐藏/重现动画。现有 --header-h 实测机制继续适配，列表定位和回到内容不会被盖住。国家按钮显示 US/UK/SG/HK 等短码，完整名称由可访问标签和国家面板提供。

NEW IN 继续使用现有 /products 入口，不擅自改变其排序或页面意义；SHOP进入 /products，SERIES进 /collections，ABOUT US进 /about。商品详情页 SHOP 激活；现有 NEW IN 和 SHOP 共用 /products 时不虚构不同的数据策略，正式实现需保证只标一个当前入口。首页四项不强行激活。

## 抽屉和国家面板

菜单打开右侧抽屉，宽 min(360px, 90vw)，保留三个系列和帮助/品牌入口。遮罩、关闭按钮、Escape均可关闭，关闭后焦点回到触发按钮。抽屉滚动、背景锁定；菜单和国家面板不叠加打开。

国家切换继续复用现有目的地面板及确认流程。原型只展示面板和选中态，保留取消；国家确认是明确禁用的演示按钮，不改变商品市场或价格。购物袋图标打开空袋演示；购买按钮仅提示这是设计预览，不创建真实购物袋、Checkout或订单。

## 原型数据和验收

sample.json 为只读 Shopify 查询样本，LITTLE HEIRESS / US / USD；图片从同一当前商品采样。仅用于设计，不作为站点商业数据回退；页面底部有设计预览标记。Logo、首页 Hero、系列图沿用现有公开品牌资产。

检查 320、375、390/393、768、1440px：两行高度、四入口、44px触控目标、无横向溢出、吸顶、侧栏开关/焦点/键盘、长名称及国家面板。原型与说明进入 docs/design，不改 src/、正式字典、主规范和部署文件；用户确认后再单独开 spec-first/TDD 实施变更。
