# 手机双行顶栏方案

状态：设计预览，待用户截图确认。正式站点未修改、未部署。

建议第一行 56px 放 OFFY Logo、国家短码、购物袋图标和菜单；第二行 44px 直接露出 NEW IN / SHOP / SERIES / ABOUT US。两行一起吸顶，原黑色提示条整体移除。桌面只移除提示条，保留现有单行导航。

侧栏用于三个系列、品牌与帮助入口，常用四导航不再依赖打开侧栏。国家面板继续使用现有确认交互；购物袋与商品页底部购买条保留。不会添加 POP MART 的收藏、分享、搜索或评论等当前未实现的功能。

用户已确认所有手机页面都使用相同四导航，所以商品页第二行不切换成 Product / Review / Recommend。原型只模拟视觉与交互：不连接购物/支付/广告事件；国家确认禁用，防止样本美元价格被误认成新市场价格。

建议通过 [设计确认稿](http://127.0.0.1:8840/review.html) 查看，电脑中也直接展示手机尺寸。页面提供商品页、首页、菜单展开、向下浏览四种场景切换。

原型入口 `index.html`（默认商品页），`?page=home` 看首页，`?page=series` 看系列入口，`?page=about` 看品牌入口。`#details` 可查看滚动后的顶栏；也可直接点菜单与国家按钮检查展开状态。商品样本来自当前只读 Shopify，采样信息在 sample.json。

待确认后实施的范围：Header 去掉轮播和计时器；手机首行紧凑化、第二行常驻；原 MobileNav 调整为补充导航；沿用 Header 实测高度，验收市场抽屉、购物袋、分类吸顶与商品底部购买条。不会混入首页选品、商品详情推荐或其他业务改动。

验收与截图见[验证记录](verification.md)。本目录是待确认设计，不表示正式改造已实施。
