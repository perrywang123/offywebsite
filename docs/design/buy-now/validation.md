# Buy Now 设计原型验收

2026-11-11。状态：设计已交付，功能待用户确认；没有修改 src、真实购物袋或支付链路。

## 内容依据

- Shopify Storefront 美国市场只读查询确认 CARAMEL RÊVE 当前为 $45.90 USD、可售，原型照片从其公开商品主图取得。
- 同次查询确认 SWAN QUEEN 的商品描述明确「不单独售卖、99 美元仅占位」。赠品建议展示 Gift with 6 OFFYs 并不新增 Buy Now；这项展示调整仍待确认，没有修改 Shopify 价格。
- 样本存于本目录 sample.json，仅用于设计，不会被正式页面导入。

## 原型验证

- 320×800、360×800、390×844、768×1024、1440×900、1920×1080 均无横向溢出；主要双按钮均为 48px 高。
- 手机 390px 下按钮各 174px，320px 下各 139px，正常与加载文字均无溢出。正常底栏高 105px，设备 safe-area 另加。
- 手机显示吸底双按钮，768px 起仅商品信息区显示双按钮，无桌面吸底条。
- 模拟 Add to Bag：原型内存计数 0→1，打开模拟购物袋；随后 Buy Now 进入双按钮禁用的加载态，模拟购物袋数量保持 1。
- 模拟快捷购买仅显示当前商品 1 件；最终说明弹窗是原型提示，不是建议增加的正式确认步骤，也没有调用 Shopify。
- 失败状态含短错误文案和 Try again，实际点击可进入加载态并显示演示结果。
- 售罄状态两按钮禁用；赠品分支没有 Buy Now、未显示 $99 占位价。
- Enter 可启动模拟 Buy Now，Escape 可关闭演示弹窗；临时浏览器视口已重置。
- 复审后将 320px 下挤成两行的加载文字缩短为 Opening…，保留读屏名称 Opening Shopify checkout；桌面 Header 恢复原 BAG 胶囊作为上下文，避免把未要求的导航变化混入提案。

## 静态检查与边界

- 两份 HTML 内联脚本语法、原型服务器语法、Prettier、OpenSpec 与 diff 空白检查通过。
- HtmlDesign 静态审计通过，有两项启发式提示：可见文字按钮未另设 aria-label、颜色字面值较多。已人工核对按钮可访问名称和同一套黑白灰角色，不将此视为正式应用缺陷。
- 仓库全量 145 个文件、915 项测试通过。此次没有应用代码变更，因此未重新构建或重启主站/后台。
- 原型服务仅绑定 127.0.0.1:8841，GET/HEAD 读取本目录及公开品牌素材；页面只读取本地 sample.json。无真实 Checkout POST、订单、付款、localStorage 或埋点操作。
- 已检查现有支付 hook 和回站清袋逻辑，后续实现约束记录于 DESIGN.md；本轮均未修改。
