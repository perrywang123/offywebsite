# 品牌首屏原型验收（待确认）

2026-11-11。仅设计原型；正式 HeroCarousel、主站服务、Shopify 与生产环境均未修改。

## 结果

- 使用当前原图 hero-brand.jpg 与 is-offy-wordmark.png，保留两句原文和七款 OFFY 的完整摄影区域。
- 真实 Chrome 检查 320、360、390、430、768、1024、1440、1920px 宽度，未出现横向溢出。正常文档流的文字块与图片区间距至少 18px。
- 390px：主句约 24px、副句约 18px，首屏高 296.8px；当前第一屏按原比例约 244.9px。
- 1440px：主句 51.84px、副句 38px，首屏 904.3px，维持原图 3250:2041 比例。
- 320px 使用原型按钮模拟 200% 文案字号，主句 40px、副句 32px；文案自动换行，首屏撑高至 392.2px，仍保持 18px 图文间距，无横向溢出。这是文案放大模拟，不等同于完整网站所有浏览器的缩放验证。
- 字体、摄影和 Logo 均来自本地现有资源，无外部 SDK、商业数据请求、轮播或支付动作。原型资产已在浏览器加载成功。
