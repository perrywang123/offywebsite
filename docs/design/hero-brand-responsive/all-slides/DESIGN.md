# 五屏补充方案（新增四屏待确认）

品牌第一屏的方案已于 2026-11-11 获用户确认；本轮继续检查另外四屏，并制作独立原型。正式 HeroCarousel 仍未修改。

## 判断与推荐

促销屏目前把文案绝对定位到固定比例横幅上。默认本地 Chrome 在 320、390、430、768、1440px 下均为两行，没有复现用户微信截图的三行裁切；因此不能断言微信自动字号就是具体根因。但按现有样式做 130% 文案字号模拟后，390px 下三行文字超出横幅约 27.4px，复现了相同的 TOTE 裁切形式。不同字体、内置浏览器字号或旧页面版本都可能触发换行，具体微信环境仍需真机验证。

推荐促销屏采用上图下文，完整保留四只袋子；标题按原文分成 BUY ANY 3 OFFYs, / GET A FREE BIG TOTE 两个语义段，允许每段继续自然换行，容器随内容撑高。字号约 28px（390px），不会靠缩小字体隐藏问题，也不限制最大行数。

三个系列默认未见截断，但手机副标题当前约 11px，推荐调整到 12–15px（390px 约 13px）。保留主标题大字、左对齐和明暗配色；保留摄影中的全部人物和原文，只在空白/地面区域布置独立的文字区。Princess、Streetwear、Dress-up 对应关系不动。

## 布局规则

- 五屏共享一个 CSS Grid 单格；不活跃屏 visibility:hidden，仍参与自然高度计算。最高内容决定框高，切屏不改变高度。
- 图像部分固定原摄影比例，不 flex 收缩；主副标题在正常文档流中，允许任意换行。
- 文案区底部为指示条保留独立高度；指示条视觉沿用五条细线，不覆盖文字。
- 品牌屏沿用已确认方案。促销照片取原图前 1050px，系列照片取前 1310px，均包含完整拍摄主体；剩余的原底图纯背景用于文字区延展，源文件不修改。
- 仅预览 HTML；导航和 NEWS 只用于上下文示意，没有真实自动播放、手势、购物车或 Shopify 请求。真实轮播的无障碍、链接、自动播放、手势和性能应在实施后单独回归。
