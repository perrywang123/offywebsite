# 五屏原型验证

日期：2026-11-11。本轮只检查与设计，未修改 src、正式站服务、Shopify 或生产配置。

## 当前组件检查

通过本地已构建站点 http://127.0.0.1:4317/ 读取真实 HeroCarousel DOM。320、390、430、768、1440px 默认字号下，促销主句均为两行，三个系列均为一行主标题，未发现容器外裁切。手机副标题为 11px。

用户截图中的微信内置浏览器环境未直接复现，不将模拟结论当作微信具体根因。独立预览按当前样式模拟字号 130%，390px 的促销标题变为三行，超出固定横幅 27.4px；推荐方案中完整显示且为指示条留有空间。

## 推荐原型检查

真实 Chrome 检查 320、360、390、430、768、1024、1440、1920px，共 8 个宽度；每个宽度按原型控件模拟 100%、130%、200% 文案字号。24 种配置 × 五屏，共 120 组检查：没有横向溢出，没有文字/Logo 与照片区域相交，没有文本侵入指示条区域。全部摄影主体已逐屏视觉复审。

390px 默认情况下五屏同高 296.8px；130% 为 349.9px；200% 为 521.6px。同一配置下五屏共同参与框高计算，切换内容不跳高。这是独立原型的排版验证，不代表真实轮播交互已经改造完成，也不等同于 iOS/微信真机验收。
