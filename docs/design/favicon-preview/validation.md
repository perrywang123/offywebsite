# 预览页 favicon 比例修正

2026-11-11。用户指出标签图标被压缩。两个 Hero 原型曾将 1084×408 的横版 PNG 直接声明为 favicon。现改为 64×64 自包含 SVG，PNG 只作等比嵌入（58×21.83），置于白色方形画布中间；原 PNG 内容和页面内 Logo 均不变。图标地址带版本参数，方便浏览器更新缓存。

正式 src/app/favicon.ico 仍是原脚手架图标，和用户截图里的 Logo 图标不同。本轮仅修正预览页 favicon 引用，不擅自替换正式品牌资产或部署生产。正式 favicon 如需统一，应随正式界面实现单独验收。

浏览器检查项：SVG 正常加载，内嵌图宽高比与原 PNG 一致，两个原型均指向新版方形图标。比例对照页中原拉伸图仅为问题示意，不作为所有浏览器实际缩放方式的断言。

Chrome 中 16/32/64px 的 SVG 图片均成功渲染，见 [比例对照截图](comparison.jpg)。浏览器自动化插件会在受控标签中注入自己的 favicon 标记，因此不将受控标签图标当作原生 favicon 的显示证据；另通过两个页面 HTTP 源码核对实际声明、SVG 响应 200 与原始宽高比。普通用户预览页使用新版声明。没有正式应用源码变更。
