# KOL 合作后台原型设计契约

状态：V2.1已批准并完成首版；本目录HTML继续保留为静态原型，正式实现见src/app/admin及运行手册。继承根 DESIGN.md 的黑白灰与系统字体，内部操作密度按账务列表调整。

## 页面目标

品牌管理员快速完成新增合作、复制链接/码、核对异常和月度结算。主入口是合作名单，核心记忆点是“每位 KOL 一份可复制合作包”。四页导航，不堆分析图表。

## 视觉命题

Offy 的合作账簿：黑白、有秩序、金额可核对。以名单与对齐表格表达运营信息，保留小号 OFFY 字标与编辑式编号。不用渐变、装饰插画、大面积统计卡或第三方品牌样式。

- 画布 #efefef，表面 #fff，墨色 #1d1915，次文字 #525252，线 #dedbd8。
- 深绿 #286348 仅表已核验/可结算；橙褐 #805316 表待核查；红 #b3402f 表同步失败。状态均附文字，不靠颜色。
- 系统 sans 中文正文；标题 28–36px；辅助文字最小 12px；金额等宽数字。代码用系统 monospace。
- 间距 4/8/12/16/24/32/48；主容器最大 1440px，桌面侧栏 208px；列表占主要面积。表单对话框不超过 680px。
- 圆角主控件 8px、标签胶囊；边框优先，浮层才用阴影。按钮至少 44px 命中高度。

## 数据与状态

所有人物/金额/码为演示且页面常驻标注；不连接 Shopify、不声称发码/付款成功。演示订单净额 USD 90 +45 +40 =175，佣金 7.20+3.60+4.00=14.80；可结算7.20，冻结7.60。关联待核验订单不进入汇总。来源展示改为当次链接 session；优惠码只提供粉丝权益，不独立归因；取消原30天点击窗口。不得显示混币合计或模拟真实转账。

## 交互与适配

导航切页、搜索名单、详情、合作包预览/复制、自定义佣金输入、新增演示草稿、Shopify已有码绑定与新码生成/同步状态、订单口径、结算草稿演示、连接失败/空白状态可检查。草稿仅当前页面内存有效；刷新重置。提供“绑定已有码/生成新码”两个入口及任务状态，无权益规则编辑或停用共享活动控件；付款外部动作禁用。dialog 支持 Esc 和焦点返回；所有控件提供焦点样式/标签。窄屏改顶部导航、名单条目分字段重排、底部保留操作；其他明细表仅自身横滚。检查360/768/1440/1920，减少动效下仍可用。

## 验收

静态审计 + 浏览器操作 + 桌面/手机截图；检查最弱三个设计决定并修正。此原型不要求应用 build/test，因为不修改运行源码；正式实现遵守 spec-first/TDD。

V2：佣金百分比为必填输入（建议0–100、两位小数、无默认），正确显示0%。优惠码页支持已有绑定与向已有活动生成新码的演示；未知码不假装已存在，生成的新码先显示同步中，显式模拟远端成功后才绑定；规则由Shopify维护，买赠和应用规则不另设实施阶段。页面字段、合作包与规则面板不得再出现固定佣金档位或“先折扣后赠品”。
