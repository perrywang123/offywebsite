# KOL 合作后台设计契约

状态：V2.1已批准并完成首版；本目录HTML保留为历史静态原型，正式实现见src/app/admin及运行手册。2026-11-04 正式后台体验审查与修订契约见下文，是否完成以当轮验收证据为准。继承根 DESIGN.md 的黑白灰与系统字体，内部操作密度按账务列表调整。

## 页面目标

品牌管理员快速完成新增合作、复制链接/码、核对异常和月度结算。主入口是合作名单，核心记忆点是“每位 KOL 一份可复制合作包”。正式后台为合作、优惠码、订单、月结、结账诊断五栏目，不堆分析图表。

## 视觉命题

Offy 的合作账簿：黑白、有秩序、金额可核对。以名单与对齐表格表达运营信息，保留小号 OFFY 字标与编辑式编号。不用渐变、装饰插画、大面积统计卡或第三方品牌样式。

- 画布 #efefef，表面 #fff，墨色 #1d1915，次文字 #525252，线 #dedbd8。
- 深绿 #286348 仅表已核验/可结算；橙褐 #805316 表待核查；红 #b3402f 表同步失败。状态均附文字，不靠颜色。
- 系统 sans 中文正文；标题 28–36px；辅助文字最小 12px；金额等宽数字。代码用系统 monospace。
- 间距 4/8/12/16/24/32/48；主容器最大 1440px，桌面侧栏 208px；列表占主要面积。表单对话框不超过 680px。
- 圆角主控件 8px、标签胶囊；边框优先，浮层才用阴影。按钮至少 44px 命中高度。

## 正式后台统一工作区契约（2026-11-04）

- 搜索、下拉和日期有可见关联标签；白底、44px控件、统一边框/圆角，标签12–13px，正文14px。字段间12px，区块间24px；刷新宽度稳定。按内容宽度换行，日期不挤压，手机搜索独行，其余最多两列。
- 下拉框闭合态箭头使用统一16px图标盒，右侧12px、垂直居中，文字右侧留40px，不贴边或侵占选项文本。手机订单展开筛选的下拉独占一行，起止日期仍相邻，保证默认币种说明完整。继续使用原生select与菜单/键盘/焦点；强制颜色模式恢复系统箭头。此规则同时覆盖订单/诊断筛选和后台弹窗。
- 当前栏目有清空筛选；日期倒置说明错误而非伪报无结果；全空与筛选无匹配分别提供恢复入口。子区空态紧凑，不重复250px大白块。
- 手机订单/诊断高级筛选默认收起，按钮显示已选项数，已选摘要/清空/错误不会隐藏；日期起止同组相邻，订单搜索与刷新同排。桌面仍直接展开高级字段。
- native dialog 采用固定头、唯一滚动正文、正常流独立操作页脚；无负 bottom，375px字段和完整按钮无交叠。原生表单验证、错误定位、Esc和返回焦点保留。
- 手机标题说明整行，连接/账户动作另成一行。表格窄屏优先同一 DOM 的带字段标签记录，金额/币种/动作完整；复杂横滚只在有名称、键盘可达的局部容器，页面本身不溢出。
- 姓名、长码、链接、原始原因可换行，关键信息至少12px。确认有后果的操作前展示目标与已有金额币种；危险动作使用明确文案和视觉区分，不改变核验、冻结和付款规则。
- 验证360/375/768/900/901/1024/1280/1440/1920px；同排筛选控件顶底差≤1px。使用隔离有数据、无匹配、长内容、负调整和多商品记录，不能只凭空表截图认定完成。

## 数据与状态（历史静态原型）

所有人物/金额/码为演示且页面常驻标注；不连接 Shopify、不声称发码/付款成功。演示订单净额 USD 90 +45 +40 =175，佣金 7.20+3.60+4.00=14.80；可结算7.20，冻结7.60。关联待核验订单不进入汇总。来源展示改为当次链接 session；优惠码只提供粉丝权益，不独立归因；取消原30天点击窗口。不得显示混币合计或模拟真实转账。
