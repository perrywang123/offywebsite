## 本轮功能检查

- 自定义佣金为数字输入，无默认值；空值required、101%越界、12.345%精度均被拦截；12.34%可临时保存，0%正确显示为0%，不是缺失。Noor示例7.25%说明不再只有固定档位。
- 新增演示草稿仅当前页面内存，刷新重置；不会写实际数据库。
- 优惠码页支持绑定已有码及生成新码同步；没有权益类型/折扣比例/赠品SKU/停活动控件。活动摘要仍只读，发码不重做权益规则。
- 未知码 `NOT-REAL` 被拒绝；小写 `maya10` 被识别为已有绑定并拒绝改绑；应用码 `fans-perk` 可读取只读摘要并绑定给演示KOL，刷新重置。没有真实Shopify调用。
- `NOOR-GIFT`展示Shopify买赠只读摘要，不标成下一阶段，不声称自动领取或自动加赠品；活动中不承诺适用于所有购物车。
- 合作包改为通用Shopify结账用码说明，不默认承诺10%折扣；佣金与码权益分离。
- 订单来源保持当次链接session；改比例只影响后续checkout，待核验不凭优惠码补归属。规则面板显示自定义佣金、Shopify码绑定、税前净额、独立访问端口/共库。
- dialog可通过Esc关闭；浏览器错误/警告日志为空。演示临时条目已刷新清理，交付页恢复初始数据。
