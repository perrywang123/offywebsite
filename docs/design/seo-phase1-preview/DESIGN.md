# SEO 第一批 · 确认稿设计契约

状态：2026-11-17，待用户确认；仅静态设计预览，不是网站实现。

目标：让品牌负责人选择 A/B 搜索图标、审阅 13 个实际路径的英文标题和摘要，并理解普通商品、赠品和预告的不同搜索表达。

视觉命题：OFFY 的搜索名片。采用现有黑白暖灰基调、清晰的编辑式排版；只有搜索链接使用蓝色。不引入假评分、价格、排名或投放数据。

颜色角色：背景 #f5f4f1，纸面 #fff，主文字 #1d1915，说明 #625f59，线条 #e3e0db，模拟搜索标题 #1a0dab。状态靠文字区分，不能只靠颜色。

字体：中文系统 sans；标题 30–44px，正文 15px/1.65，英文搜索标题桌面 21px、手机 20px，摘要 14px/1.6，路径和字符数 12px。中文和英文都自然换行。

布局：最大 1160px，桌面左右 40px，手机 20px；图标对比为当前+A+B，手机当前占一行、A/B 并列，以同屏比较小图标。搜索预览为左侧完整文案+右侧模拟结果，窄屏依次排列。

交互：A/B 真实大小预览联动；13 页下拉切换；桌面/手机模拟；展开当前 metadata 与完整文案清单；支持复制文案。没有保存到网站、发布、付款或下单按钮。所有控件至少 44px 目标区、可见焦点。

证据：当前 metadata 取自当日公开线上 HTML；建议文案为草案；图标为 imagegen 概念稿。普通商品示例取已核实描述，赠品不暗示单独售卖，包挂预告不暗示已发售。Google 可以重写标题和摘要，且可能继续缓存旧图标。

边界：不改 src/、public/、Shopify、服务器证书/Nginx、商品名称与价格、国家判断、购物袋、结账、支付或归因；用户确认后才创建实现阶段的 OpenSpec/TDD 工作。

验收：浏览器检查 360、768、1440、1920px；检查图片加载、小尺寸图标、页面切换、A/B 联动、当前/建议文案区别、复制失败提示、焦点和溢出。
