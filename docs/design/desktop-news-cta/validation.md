# 桌面 NEWS 主卡按钮

2026-11-11。本轮仅调整真实 NewsGrid 主卡的桌面响应式尺寸，更新本地 standalone 与 Git；未部署生产、未修改 Shopify。

## 调整

- <1024px 维持原先的 40% 卡宽、176px 上限、40–48px 高和 12–16px 字号。
- ≥1024px 为 48% 卡宽、320px 上限、52–64px 高和 18–24px 字号；桌面距底部改为 2%，为限量标识留空。
- 延续原黑色胶囊、水平居中、整卡链接、图片裁切。副卡、首页精选、国家、购物袋和支付代码未修改。

## 验证方法

先在旧真实页面读取几何：1440px 下只有 176×48px，不满足本轮「至少 240px 宽」验收目标；390px 手机基线为约 143.2×40px。采用浏览器尺寸断言验证样式，避免用 jsdom 的 class 字符串代替真实布局验证。

第一轮实现后，1440px 已达到约 268.5×55.9px、字号约 19.6px、水平居中误差 0；复审 1024px 边界后进一步将桌面按钮从底部 4% 下移到 2%，保留手机原位置。

最终浏览器检查：

| 视口宽度 | 按钮宽×高                | 字号    |
| -------- | ------------------------ | ------- |
| 390px    | 143.2×40px，与调整前一致 | 12.53px |
| 768px    | 176×48px，保持原样       | 16px    |
| 1024px   | 189.5×52px               | 18px    |
| 1440px   | 268.5×55.9px             | 19.58px |
| 1920px   | 320×64px                 | 24px    |

五种尺寸均无横向溢出，主卡按钮水平居中误差不超过 0.004px；1024px、1440px、1920px 截图复查限量标识不被覆盖。点击主卡确实进入本地 `/products/swan-princess`，显示对应 Shopify 商品标题，没有加购或发起结账。已恢复浏览器临时视口。

最终全量 Vitest：149 个文件、935 项通过；生产构建通过，包含 ESLint 与 Next.js 类型检查。尺寸调整涉及纯样式，因此没有新增镜像 class 实现的组件断言，新增验收由上述真实浏览器几何与截图承担。
