# Offy 管理员 SOP｜Collabs 合作、推广上线与佣金核对

适用对象：Offy 品牌运营、合作负责人和对账管理员。更新：2026-11-07。

## 先明确两个系统各自负责什么

**在 Shopify Collabs 建立合作、分配计划、生成官方推广链接和优惠码、查看归因及佣金并自动付款；在 Offy 后台保存链接索引、导入官方报告、核对 Shopify 订单和排查结账异常。** Offy 后台不是另一套计佣或打款平台，里面的报告也不是实时 Collabs 余额。

品牌合作联系人统一为 **yifangu3@gmail.com**，已在 Collabs 验证。Offy 管理员登录邮箱与合作邮箱是两种身份，不要把管理员密码交给 KOL。KOL 只使用自己的 [Collabs 官方门户](https://collabs.shopify.com/)。

常用入口：

- [Shopify Collabs 商家后台](https://admin.shopify.com/store/ujc6x6-41/apps/collabs)：邀请、计划、链接、佣金和付款。
- [Offy 管理后台](https://isoffy.com:8443/admin/collabs)：Collabs 核对与结账诊断；需要管理员权限。
- [Offy 独立站](https://isoffy.com/)：顾客浏览商品并跳到 Shopify 托管结账。

## 第一步：先确定合作条件，再创建邀请制计划

与 KOL 确认合作邮箱、社媒主页、适用商品或系列、佣金比例、粉丝优惠、合作起止日以及发布要求。把这些条件保留在双方确认的合作记录中；本 SOP 不默认所有 KOL 都是10%佣金。

进入 Collabs → **Programs → Create invite program**。设置计划名称、链接落地页、粉丝优惠和佣金比例后保存，再检查一次。不同条件可以使用不同邀请制计划；一个创作者同一时间只能属于本品牌的一个计划，移入其他计划会改变其适用权益，不能把它当成仅改一个内部标签。[官方计划说明](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/collabs-programs)

首期保持邀请制，不启用 Open Access。粉丝赠品规则、优惠适用条件和叠加限制在 Shopify/Collabs 核实；在 Offy 新增链接记录不会创建优惠码，也不会为 KOL 生效佣金。普通 Shopify 优惠码不能仅凭名称就认定已经与 Collabs 创作者绑定。

## 第二步：发送邀请，让 KOL 完成自己的账号与收款设置

进入 **Recruiting → Invite creators**，输入双方已确认的 KOL 邮箱，选择正确的计划，检查专属代码和邮件预览，再发送。邀请前检查联系人仍为 yifangu3@gmail.com、计划和费率无误。当前官方支持品牌直接邀请，邀请有效期30天；不要让新 KOL 从公开自由注册入口反复尝试。[邀请操作](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/recruiting-creators)、[创作者账号说明](https://help.shopify.com/en/manual/promoting-marketing/collabs/creators)

让 KOL 用收到邀请的同一身份接受合作，确认品牌为 is.offy，并检查佣金、粉丝权益和付款条款。KOL 应在其官方账号完成自动收款开通；品牌不代收银行卡、证件、验证码或账号密码。发送本文配套的 KOL SOP 即可，无需提供 Offy 管理员账号。

## 第三步：保留完整官方链接，再按需建立 Offy 短链

先从 Collabs 获取该创作者已分配的**完整官方推广链接和代码**。如果要让内容落在 Offy 独立站，可到 Offy 后台的 **Collabs 核对 → 合作链接索引 → 新增链接记录**，填写：

1. **达人名称**：管理员识别用的名称。
2. **固定推广别名**：小写字母、数字或连字符，例如 `maya`；保存后会得到 `https://isoffy.com/r/maya`，不用新增页面或重新部署。
3. **报告中的创作者标识**：按真实报告中的身份原样填写；首次没有报告时先保存官方身份依据，避免将临时昵称误认为最终报表标识，不能确定时暂缓建档。
4. **Collabs 官方推广链接**：原样复制本店链接，不删除 `dt_id`、优惠码或其他原生参数。
5. 勾选启用短链，点击 **保存链接记录**，再打开生成的链接核对落地页。

后台只接受本品牌 Offy 域名或本店 myshopify.com 的安全官方链接。若个性化地址解析失败，从 Collabs 复制带追踪参数的完整地址再试，不要随便补一个 `dt_id`。别名和来源身份创建后保留，不能将 Maya 的旧别名转给另一个人。

短链只是经过验证的官方链接入口。停用 Offy 短链只关闭这一入口；**不等于停止 Collabs 合作，也不会自动撤销优惠码或已有佣金义务**。结束合作要另外到 Collabs 处理。[官方 Headless 要求](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/custom-storefronts)

## 第四步：首位 KOL 发布前做一次完整试点

目前普通购物、隔离报告导入及退款提示已经测试；真实 KOL 的官方归因、实际导出字段和到账仍需首位合作试点。不要把脚本加载成功、一次 HTTP 200 或普通结账成功当成已证明 KOL 计佣。

由品牌和首位 KOL 协作完成以下验收，再扩大合作：

1. 从最终发布位置点开链接，包括准备实际使用的 Instagram/TikTok 内置浏览器；确认进入正确商品、追踪参数保留、优惠符合计划。
2. 经品牌明确批准测试订单与预算后，完成一笔符合计划条件的真实购买，记录订单号、时间、币种及所用链接/代码。没有批准时停在未付款结账，不能标作转化验收。
3. 管理员在 Shopify 订单的 **Conversion summary → View conversion details** 检查来源旅程，在 Collabs 对应创作者下检查转化与佣金；KOL 同时在自己的门户核对。
4. 等官方数据出现后导出首份报告，核实实际字段、粒度和币种，再在 Offy 导入并对账。
5. 分别检查只用代码、不同 KOL 链接与代码冲突、取消及部分/全额退款、隐私拒绝、跨设备和 Shop 渠道。不能安全执行的案例记录为待验证，不猜测结果。

当前采用 Collabs 原生规则，已不再使用 Offy 旧的“仅当次 session”计佣。当前店铺已读到90天链接归因窗口；这不意味着任意购买都必定归属于该 KOL。Shop/Shop.com 入口不经过 Offy 时，不会产生 Offy 的结账准备记录，应在 Shopify 和 Collabs 核对，不能用 Offy 无记录来判定未成交。

## 第五步：日常看数，统一报告期间与币种

在 Collabs 的 **Connections → 创作者** 查看其表现；从销售报告入口选择时间范围、计划等条件并导出。先记录筛选条件、导出时间和报告时区，再与 KOL 比较。Visits、订单、销售额、佣金和付款金额是不同指标，不要用点击数推算订单数，也不要用商品销量乘单价冒充官方销售额。[商家表现与报告](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/managing-creators)

如果两边数字不同，先检查日期、时区、币种、创作者身份、订单退款和报告刷新时间。KOL 官方 Analytics 的统计展示不一定与品牌的自选期间一致；先确认比较口径，再联系 Shopify 排查。

## 第六步：把官方 CSV 导入 Offy，并发起只读核对

打开 **Collabs 核对 → 导入报告**，按下面的顺序操作：

1. 选择官方原始 CSV，每次不超过 **2 MiB、2000行**。只保留核对必需的信息；避免上传包含无关客户个人信息的文件。
2. 选择实际报告类型：销售/佣金、账单或付款报告。选择真实来源粒度：逐笔订单、每位达人汇总或期间汇总；不能将达人汇总误选为逐笔订单。
3. 填写与原报告一致的起止日和数字格式。销售额口径无法证明时保留“未确认，暂不比较销售额”。
4. 逐项映射实际列。**必须有真实币种列和至少一个金额列**；逐笔还需订单号或 Shopify 订单 GID，达人汇总还需创作者标识。没有的字段保留“来源未提供”，不能填0、不能猜币种。
5. 如果原导出没有必要列，停止导入并保留原文件，请技术人员根据真实格式适配；不要为通过校验伪造列或把截图中的数字拼成“官方 CSV”。
6. 重叠报告要选择被替代的旧报告，或确认保留独立快照。修订文件不应与原文件相加成为佣金余额。
7. 核对来源声明，点击 **校验并预览**。检查首行、币种及缺失提示；修正字段后重新预览，再点击 **确认导入此快照**。
8. 在报告详情点击 **开始只读核对**。后台按小批次查询订单；看到“本轮完成”再判断结果。中断时保留未完成状态，恢复连接后重新检查，不能把已检查部分当作全量通过。
9. 对差异逐项核查，在 **追加复核说明 → 保存说明** 记录依据和后续动作。原金额、旧报告和历史核对保留，不直接改写官方佣金。

相同文件和口径重复提交会返回已有快照。不同币种分别展示；USD 0.00 是来源真的为零，“未提供”表示缺少证据。汇总报告可以留档，但不能据此声称核实了每一笔 Shopify 订单。只读核对通过也不证明 Collabs 归因、计佣或银行到账正确。

## 第七步：分清佣金、平台处理费和 KOL 到账

当前店铺冻结期为 **30天**。冻结结束后进入 Shopify 账单流程，不能承诺“第30天一定到账”。管理员应检查账单支付是否正常、KOL 是否开通收款，以及 Collabs 的实际付款状态。自动佣金付款目前另收佣金金额的 **2.9%** 处理费，品牌账单和换汇等其他费用另核。[商家付款规则](https://help.shopify.com/en/manual/promoting-marketing/collabs/merchants/payments)

例如，2026-11-07主站核到 WILD SWEETIE 为 **USD45.90**。假设此商品全部金额可计佣、无折扣，且计划佣金为10%，示意佣金为45.90×10%=USD4.59，处理费约USD0.13，品牌的佣金及该项处理费合计约USD4.72。若粉丝优惠10%、佣金比例7.5%，并假设计佣基数就是折后USD41.31，则示意佣金约USD3.10。**这是说明算法的假设示例，不是已生效的优惠或对实际订单的承诺**；商品范围、退款调整、逐行舍入、费用和最终金额均查看 Collabs 原始明细与账单。

| 页面状态            | 管理员下一步                                                            |
| ------------------- | ----------------------------------------------------------------------- |
| Holding period      | 仍在冻结期；检查退款或异常，在期限内处理争议。                          |
| In dispute          | 阅读并处理争议，保留证据；不要在 Offy 用复核备注替代正式处理。          |
| Waiting for creator | 联系 KOL 完成官方收款开通；不要先在外部补付，避免之后自动付款造成重复。 |
| Scheduled           | 核对后续 Shopify 账单和计划付款；不向 KOL 承诺当天到账。                |
| Paid                | 核对具体付款记录及参考号；银行实际到账由 KOL 自己确认。                 |
| Canceled            | 查看对应订单和取消依据，不仅凭标签推断原因。                            |

每次对账分别保存销售/佣金来源、Shopify 账单及官方付款证据。Offy 第一版为人工报告导入，并未自动拉取 Collabs 全部过程数据或 KOL 银行到账。不要为同一笔 Collabs 佣金在旧月结、PayPal或线下再付款。

## 第八步：出现结账失败时保留可追查信息

在 **结账诊断** 按大致时间、商品或记录编号筛选，查看国家判定来源、选中商品、Shopify 返回和失败阶段。记录不依赖顾客先填写邮箱，但只覆盖 Offy 发起的结账准备；不是所有 Shopify 托管页面后续行为的完整录像。

“已生成跳转链接”仅表示 Offy 得到了 Shopify 链接，不表示顾客已到达或完成付款。若 Shopify 页面在填邮箱前提示 Sold out，保留该次完整 checkout 链接、时间和商品，结合诊断中的 country/buyerIdentity 向 Shopify 排查。完整链接只提供给授权人员或官方客服，不公开贴到 KOL 群里。

若仅 Offy 失败，先核对该次请求与服务端响应；若 Offy 和 Shop 都失败，另核查 Shopify 共享的市场、渠道和结账上下文。没有报错记录不代表交易成功。当前诊断页面注明记录保留30天、敏感原文7天，异常应及时处理。

## 每周与每月固定动作

每周检查新增合作、链接和优惠是否仍有效，关注退款、争议和 Waiting for creator，及时处理未完成核对。每月按同一期间导出报告，逐币种核对销售、佣金、处理费和付款证据，追加差异说明，再向 KOL 说明已确认和待处理的部分。

服务更新后若浏览器仍显示旧的“合作达人/订单佣金/月度结算”侧栏，重新载入 Offy 管理后台以取得新版页面；当前 Collabs 模式应显示“Collabs 核对”和“结账诊断”。不要为了恢复旧菜单开启本地结算。

结束合作时，先核对在途佣金，再在 Collabs 处理连接和权益，最后停用 Offy 短链。不要通过卸载 Collabs、轮换主站令牌或切回旧计佣模式来临时处理对账问题。
