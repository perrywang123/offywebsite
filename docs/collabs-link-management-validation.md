# 合作链接唯一绑定与每日明细验收

日期：2026-11-08。范围仅为管理后台：防止新增/改绑时复用官方dt_id或优惠码、提示历史重复、每日明细缺失请求数显示0。没有新增PV/UV采集，没有修改独立站入口、购物袋、结账、Shopify配置或佣金规则。

先验证OpenSpec，再运行失败测试，分别复现每日0单元格缺失和重复dt_id可保存。实现后：116个测试文件、808项测试通过，TypeScript、ESLint、相关文件Prettier、`git diff --check`和standalone生产构建通过。旧迁移夹具将“别名重复”和“推广标识重复”拆开为独立输入，仍验证原有别名/报告身份唯一约束，没有放宽断言。

基本边界覆盖：同一dt_id换路径/UTM或URL编码仍拒绝；停用记录保留标识；优惠码不区分大小写；修改现有记录到冲突目标会回滚，拒绝操作不新增记录或审计；重复dt_id参数/异常值拒绝；历史重复允许不改变标识的维护及换成不同未占用标识。校验和写入使用同一SQLite immediate事务。

隔离HTTP工作流33项通过，包含真实管理员接口拒绝重复绑定；使用独立SQLite及Shopify模拟器，没有连接真实支付网关。浏览器实际提交重复链接后看到具体错误，输入保留，记录没有新增；人为准备的历史重复夹具显示冲突而不自动停用。每日明细实际渲染为数字0，图表采集边界仍保留；360、768、1440、1920像素视口检查，未见整页横向溢出。上述过程数据仅存在于隔离数据库。

只读检查真实店铺入口：myshopify.com/OFFYTESTPERRY返回301到同一Shopify域名的products?dt_id=3689395，没有进入Offy。官方链接追踪标识不是由Offy每次邀请时生成。按dt_id的Offy落地PV与匿名浏览器UV在[方案](collabs-traffic-proposal.md)中明确标为待确认，不能声称已采集访客数。
