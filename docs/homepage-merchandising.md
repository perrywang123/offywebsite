# 首页精选与区域限定

状态：2026-11-11 已完成本地实现、测试和浏览器验收，等待用户确认截图；尚未发布生产。原三个系列的归属、页面和排序保持独立。

## Shopify 后续配置

在产品 → 产品系列创建一个专用集合，建议名称 `Home Featured`（首页精选），确认搜索引擎列表中的 URL handle 为 **`home-featured`**。手动加入现有商品，把排序方式设为手动，再拖动商品并保存。将此集合设为 Offy 独立站使用的 Headless 渠道可读取；无需修改原三个系列、商品价格、库存、销售国家或订单。

建议选 8～10 款候选。首页按集合顺序取当前收货国家可售、属于原三个系列且非区域限定的前 6 款；重复商品只显示一次，不属于三系列的周边不进入此区。缺货/不可售/限定候选跳过，继续从该集合后面的候选补位。只保存商品引用及集合顺序，商品信息仍从 Shopify 当前市场读取；以后调整集合内容和顺序无需重新部署代码。

## 尚未配置集合时

集合不存在、未向当前 Storefront 发布、网络/GraphQL/字段验证失败时，首页回到 **New Looks**：三个原系列各取最新创建的两款可售商品，按原系列顺序拼接并去重。区域限定在每系列取两款前排除，因此会由后面的普通款补位。无创建时间的商品仍视为最旧。

这只是选品策略回退：数据仍然必须来自成功的实时 Shopify 响应，不能使用本地快照、旧价或伪造售罄。原系列读取也失败时展示品牌化重试提示。集合成功读取但为空，或商品全部被明确排除时，保留空精选状态和商品目录入口，不静默替换运营选择。

## 区域限定与页面

沿用现有 Shopify 多国家可见性判定与 US/GB/SG/HK 展示范围；在首页严格要求该次判定完整。判定失败时不把空结果当作“没有限定商品”，而是保留 NEWS 等独立有效内容并提供重试。限定款仅进入独立的 Regional Exclusives 区，主推荐与限定区没有重复身份。只有探测到单一国家可见时才出现对应 ONLY 标识；多国家可见不声称只在某一国家销售。它是已配置国家范围内的可见性观察，不是修改 Shopify 市场规则。

主区为最大 1280px 的桌面三列/手机两列，方形 contain 图片画布，名称/金额/币种常显。限定卡片更紧凑，单款不拉满宽屏。原圆形名册由三个真实系列入口替代；这些入口使用原来的路由和 Shopify 集合名称。首页 NEWS 的五张本地宣传图不变。其他页面的 ProductCard 及结账逻辑不变。
