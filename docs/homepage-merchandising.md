# 首页精选与区域限定

状态：2026-11-11，按用户纠正恢复原商品展示风格；本地验证完成后提交截图确认，尚未发布生产。原三个系列的归属、页面和排序保持独立。

## Shopify 配置与读取

已只读确认用户创建的集合名称为 **FEATURED**，URL handle 为 **`featured`**，当前 Storefront 可以读取。本次代码将此前约定但未创建的 `home-featured` 改为 `featured`，没有创建、编辑或发布 Shopify 商品及集合。

以后在 Shopify 产品 → 产品系列 → FEATURED 中维护现有商品，排序方式使用手动，拖动后保存；集合需保持对 Offy 使用的 Headless 渠道可读。首页按集合实际顺序取当前国家可售、属于原三个系列且非区域限定的前六款，重复商品只显示一次。缺货/不可售/限定候选跳过，继续从集合后面的候选补位。调整现有集合内容和顺序无需重新部署代码，也不改变原系列或库存。

## 集合读取失败时

集合不存在、未向当前 Storefront 发布、网络/GraphQL/字段验证失败时，仍由三个原系列各取最新创建的两款可售商品，按原系列顺序拼接并去重。区域限定在每系列取两款前排除；无创建时间的商品视为最旧。页面标题仍统一为 **FEATURED**，仅数据来源变化。

所有商品事实仍来自成功的实时 Shopify 响应。禁止本地快照、旧价或伪造售罄；原系列读取失败时展示品牌化重试提示。集合成功读取但为空，或商品全部被明确排除时，保留空精选状态和商品目录入口，不替换运营选择。

## 保留原风格与完整名册

保留 Shop by Category 标题、原 container-site 宽度和 section-y 间距、共享 ProductCard 的 4:5 cover 大图、常显名称与市场价格、红色区域角标。桌面三列/手机两列。**FEATURED** 与 **REGIONAL EXCLUSIVE** 为同字号、字重和层级的标题，均置于各自网格上方；移除上一版收窄方形画布和限定侧栏。

下方恢复 **All Products** 圆形缩略图名册，读取当前国家的全部非周边公仔，不受精选六款限制。保留原名称和商品详情链接，名册与精选/限定区的重复是有意保留的全商品索引。完整目录成功时独立展示；目录读取失败时不展示不可信名册。撤回替代名册的三系列入口条；原三个系列的页面与其他既有入口不变。NEWS 五张本地宣传图不变。

## 区域规则

沿用原 Shopify 多国家可见性判定与 US/GB/SG/HK 展示范围；首页要求该次判定完整。判定失败时不将空结果视作没有限定商品，保留 NEWS 与名册等独立有效内容并提供重试。限定款仅进入独立 REGIONAL EXCLUSIVE 区，与 FEATURED 无重复身份。只有探测到单一国家可见时才出现对应 ONLY 标识；多国家可见不声称只在某一国家销售。

验证与截图见[验收记录](homepage-merchandising-verification.md)。当前变更为 restore-homepage-product-style；先前方形布局的截图属于被用户否决的旧样式，不作为当前验收依据。
