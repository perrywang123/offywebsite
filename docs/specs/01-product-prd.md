# 产品范围与数据事实

状态：当前实现，2026-10-31。历史早期 PRD 见 [历史索引](../history/README.md)。

## 产品目标

通过原创 OFFY 形象、故事和造型摄影建立品牌认知，支持浏览真实商品、加购和跳转 Shopify 结账。公开语言为英文，不提供客户账户/会员/订单中心。

## 商品体系

三大站点系列：princess-lady、outdoor-sporty、playful-life；系列名称取 Shopify，路由映射和视觉资产本地维护。未归入三个已知 Collection 的商品使用 merch，统一置于 All Looks 末尾，不出现在首页名册。不要用早期的九系列/固定 SKU 数或编码价格档位重新生成目录。

code=Shopify handle，是路由/购物袋/服务解析标识；SKU 来自首个 variant，是给人看的商品编码。当前一件商品只选首个 variant，没有规格选择器。商品数随市场发布变化；0 价可能是后台真实配置，不能把网络失败也表示成 0。

## 核心流程

首页/系列/列表 → 详情 → 本地购物袋 → 服务端解析商品 → Shopify Cart → 托管支付与订单。品牌故事/合作联系/订阅/包挂预告提供非交易路径。

## 当前边界与待做

商品事实仅用 Shopify，不再回退本地快照或覆盖商业字段；失败使用 [已确认的故障展示](../shopify-unavailable-design.md)。主链路订单由 Shopify 管理，本站没有 Shopify 订单写回、库存管理后台或发货界面。

恢复中文、增加多规格、运营控制台和分析能力属于后续独立需求，见 [路线图](../roadmap.md)。品牌与法务正文不得为了填充版面而虚构。
