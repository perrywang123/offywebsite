# 当前交互流程与状态

基线：2026-10-31；当前源码不是早期的 CASETiFY 规格选择草案。

## 浏览与选购

- Hero 五屏，整屏链接，底部指示条、鼠标/触屏手势与自动播放；CTA/箭头开关关闭，无暂停按钮。
- New Looks 每系列两款最新创建的可售商品；区域限定依访客国家；圆形名册不含周边。
- 分类条为路由导航，不是客户端筛选器；All Looks 包括周边。
- 详情主图可由本商品缩略图切换；同系列换款入口位于页尾，最多六款。
- 手机 <768px 使用 sticky 吸底购买条；桌面使用信息区按钮。手机与桌面购买按钮均按实时可售状态禁用。

## 购物袋与结账

购物袋同款合并，数量 1–99，减至 0 删除；抽屉/独立页读取同一个 CartProvider。只持久化 code/quantity，不存价格快照。打开 CartDrawer 锁滚动并移焦关闭按钮；Escape/遮罩关闭。抽屉支持 Tab 圈闭，关闭后恢复至打开入口。

Checkout 直接创建 Shopify Cart；提交期间禁用防重复。4xx 留原地显示商品名和移除重试指引；网络/5xx/缺跳转地址留在当前页面，提示保留购物袋并允许重试。备用页依旧是 Shopify，保留地址表单，但当前 provider 不使用该 email/shipping 输入。

Shopify 回站 `/checkout/return` 清袋并以条件文案说明确认邮件；它没有验付结果。旧 Stripe/PayPal 成功页用高熵凭证查询本地订单，订单未到时呈现确认中，但没有完整轮询恢复。

## 内容交互

包挂预告 View 是 quick view：hover 1s、点击钉住、遮罩/Escape/关闭按钮退出；Portal 到 body。FAQ 用原生 details/summary，保留段落、加粗和分部编号。

## 故障改造

已区分加载、真实空集、确认404、售罄和不可用；失败不显示旧价/假空袋，重试恢复后展示当前数据。见 [已实现方案](../shopify-unavailable-design.md)。
